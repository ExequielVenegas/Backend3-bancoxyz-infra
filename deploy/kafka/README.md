# Kafka en AWS

Configuración y scripts para ejecutar Kafka en EC2 con KRaft, sin ZooKeeper.

Kafka transporta comandos de cuentas y pagos, sus resultados y mensajes fallidos. Los clientes se conectan por el puerto 9093 con SASL_SSL y permisos por tópico.

Ver [las instrucciones de despliegue](../../entrega-eft/despliegue.md).
